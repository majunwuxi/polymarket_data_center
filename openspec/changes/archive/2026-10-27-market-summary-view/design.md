# Design

## Context

本地成交包含买卖双方记录且可能存在重复或遗漏，需避免重复计入网站总额或视为当前持仓。

## Goals / Non-Goals

**Goals:** 每个盘口分别按结果与买卖方向汇总，保留小数精度并显示钱包数量和记录状态。

**Non-Goals:** 不将双边成交相加作为总投注额，不计算净流入或真实持仓。

## Decisions

按市场唯一标识汇总本地数据库，按结果和方向分别计算价格乘份数之和，金额无效时展示异常数量；记录数包含无效数据。空盘口显示暂无记录。逐笔 API 暂保留但页面以汇总为主。

## Risks / Trade-offs

- [本地成交不完整或重复] → 明示本地口径与不确定性，不声称等于网站数据。
- [大数据量] → 按比赛读取及逐条处理，避免前端下载全部成交。
