# Spec Delta

## Purpose

展示一场 NBA 比赛已保存的指定盘口和钱包成交明细，让用户能够查看本地已记录的数据，并了解数据覆盖和保留期限的限制。

## ADDED Requirements

### Requirement: 单场盘口与交易明细
系统 SHALL 展示比赛身份、北京时间、三类全场盘口及分页的本地交易记录，包括钱包、方向、结果、份数、价格和金额估算。

#### Scenario: 已有交易
- **WHEN** 比赛已有采集交易
- **THEN** 页面按盘口及时间展示真实记录，可查看后续页且标明金额口径

#### Scenario: 没有交易或比赛不存在
- **WHEN** 比赛尚无记录、已清理或不存在
- **THEN** 页面显示明确状态，不展示虚构交易

### Requirement: 数据限制
系统 SHALL 提示交易记录可能缺失或重复，买卖双方记录不能直接相加作为投注总额，且超过保留期限可能被删除。

#### Scenario: 查看详情
- **WHEN** 用户打开比赛详情
- **THEN** 页面展示上述限制并区分记录与真实持仓
