# Design

## Context

日历有赛程，数据库按市场保存原始成交；成交包含买卖双方记录且交易身份可能不确定。

## Goals / Non-Goals

**Goals:** 可从日历打开单场详情，清楚展示三类盘口与分页交易明细。

**Non-Goals:** 不声称数据完整，不将双边记录相加当作投注总额或推断钱包最终持仓。

## Decisions

只读查询 SQLite，按比赛和真实市场类型过滤；每笔展示时间、钱包、方向、结果、份数、价格及金额估算。钱包和盘口内容使用文本渲染，查询分页并允许切换类别。未保存、查询失败、清理后或未知比赛均明确提示；详情自动刷新。

## Risks / Trade-offs

- [身份及双边口径不确定] → 页面标注记录不能直接相加及可能漏重。
- [自动清理删除赛后明细] → 说明期限及空状态，无法永久回看。
